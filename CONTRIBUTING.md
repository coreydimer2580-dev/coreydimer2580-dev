# Contributing

Thanks for helping improve this profile or its project information.

## Suggest an improvement

Open an issue using the **Project or profile suggestion** form. Be specific about what should change, why it would help, and which page or repository is affected.

## Submit a pull request

1. Keep changes focused and explain the problem they solve.
2. Do not include passwords, API keys, private messages, personal data, or confidential material.
3. For changes to the website, keep it static and accessible: use semantic HTML, responsive styles, and descriptive link text.
4. A maintainer reviews every proposal. Submissions are not automatically approved or merged.

## Scope

This repository is a profile and project overview. Suggestions should be accurate, respectful, and supported by publicly shareable information. Do not claim affiliations, credentials, services, or endorsements that have not been verified by the maintainer.
